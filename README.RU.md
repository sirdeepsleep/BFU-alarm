# installationFireWall

[EN](README.md) / **RU**

Приложение для создания заглушек и блокираторов для указанных имен пакетов

Заглушка: пустое приложение с тем же именем пакета

Блокиратор: пустое приложение с другим именем пакета, создающее permission библиотеки androidX с целевым именем пакета, чтобы создавать конфликт при попытке установки целевого пакета, если он использует ту библиотеку

Для чего это можно использовать:

Если у ваш производитель телефона хочет предустановить ненужную вам программу, вы должны установить заглушку до того как он это сделает

Блокиратор служит для другой цели:  
Не занимать целевое имя пакета напрямую, чтобы его сложнее было обнаружить, но блокировать установку целевого пакета за счет конфликта permission

Это можно использовать в сценариях когда на вас давят, чтобы вы установили какую-то программу, но вы хотите скрытно отказаться, показав что программа не устанавливается
